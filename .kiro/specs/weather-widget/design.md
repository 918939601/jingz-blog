# 天气模块设计文档

## 概述

天气模块是一个客户端组件，集成在首页中，用于展示用户所在地的实时天气信息。该模块通过 IP 地址定位用户位置，然后调用天气 API 获取数据并以美观的卡片形式展示。

### 数据流

1. **初始化阶段**
   - 组件挂载时，触发 IP 地理位置查询
   - 获取用户的城市、国家、坐标信息

2. **天气数据获取**
   - 基于位置坐标调用天气 API
   - 获取当前天气、温度、湿度、风速等数据

3. **显示与更新**
   - 渲染天气卡片
   - 每 10 分钟自动更新一次
   - 支持手动刷新

## 组件与接口

### WeatherWidget 组件

**职责**: 主容器组件，管理天气数据的获取和显示

**Props**: 无

**State**:
- `location`: 位置信息对象 `{ city, country, lat, lon }`
- `weather`: 天气数据对象 `{ temp, description, feelsLike, humidity, windSpeed, icon }`
- `loading`: 布尔值，表示数据加载状态
- `error`: 错误信息字符串或 null

**方法**:
- `fetchLocation()`: 通过 IP 获取位置信息
- `fetchWeather(lat, lon)`: 通过坐标获取天气数据
- `handleRefresh()`: 手动刷新天气数据
- `setupAutoRefresh()`: 设置自动刷新定时器

### WeatherCard 组件

**职责**: 展示天气信息的卡片组件

**Props**:
- `location`: 位置信息
- `weather`: 天气数据
- `loading`: 加载状态
- `error`: 错误信息
- `onRefresh`: 刷新回调函数

**特点**:
- 响应式设计，适配桌面和移动设备
- 包含天气图标或 Lottie 动画
- 显示详细的天气信息

## 数据模型

### Location 对象

```typescript
interface Location {
  city: string;           // 城市名称
  country: string;        // 国家名称
  countryCode: string;    // 国家代码
  latitude: number;       // 纬度
  longitude: number;      // 经度
  timezone: string;       // 时区
}
```

### Weather 对象

```typescript
interface Weather {
  temperature: number;    // 当前温度（摄氏度）
  description: string;    // 天气描述
  feelsLike: number;      // 体感温度
  humidity: number;       // 湿度百分比
  windSpeed: number;      // 风速（km/h）
  icon: string;           // 天气图标代码
  pressure: number;       // 气压
  visibility: number;     // 能见度
}
```

### 推荐方案：右侧边栏 + 响应式

**桌面端 (≥1024px)**:
- 天气模块固定在右侧，宽度约 280px
- 与主内容区域并排显示
- 使用 `sticky` 定位，随页面滚动

**平板端 (768px - 1023px)**:
- 天气模块宽度调整为 240px
- 保持右侧布局

**移动端 (< 768px)**:
- 天气模块显示为横向条形，宽度 100%
- 放在主内容上方或下方
- 采用紧凑的信息展示

### 样式设计

**卡片样式**:
- 背景: 半透明深色 `bg-black/30 backdrop-blur-md`
- 边框: 细边框 `border border-white/10`
- 圆角: `rounded-lg`
- 阴影: `shadow-lg`
- 内边距: `p-4`

**文本样式**:
- 标题: 大号加粗 `text-lg font-bold`
- 温度: 超大号 `text-4xl font-bold`
- 描述: 中等大小 `text-sm`
- 颜色: 使用渐变色或亮色文本

**图标**:
- 使用 Emoji 或 SVG 图标
- 或集成 Lottie 动画天气图标库
- 大小: 48px - 64px

**交互效果**:
- 刷新按钮: 悬停时改变颜色，点击时旋转
- 加载状态: 显示加载动画
- 错误状态: 显示友好的错误提示

## 错误处理

### 错误场景

1. **IP 地理位置获取失败**
   - 显示: "无法获取位置信息"
   - 降级: 使用默认位置（如北京）

2. **天气 API 调用失败**
   - 显示: "天气数据加载失败，请稍后重试"
   - 重试: 自动重试 2 次

3. **网络超时**
   - 显示: "网络连接超时"
   - 降级: 显示缓存的天气数据（如有）

4. **API 限流**
   - 显示: "请求过于频繁，请稍后再试"
   - 处理: 增加重试间隔

## 技术选型

### 第三方服务

1. **IP 地理位置 API**
   - 选项: `ip-api.com` (免费), `ipstack.com`, `maxmind.com`
   - 推荐: `ip-api.com` (免费且可靠)

2. **天气 API**
   - 选项: `openweathermap.org`, `weatherapi.com`, `open-meteo.com`
   - 推荐: `open-meteo.com` (免费，无需 API Key)

### 前端库

- **动画**: 使用现有的 `motion/react` 库
- **图标**: 使用 Emoji 或集成 `react-icons`
- **HTTP 请求**: 使用现有的 `fetch` 或 `axios`

## 性能考虑

- 使用 React 的 `useEffect` 管理数据获取和自动刷新
- 实现请求缓存，避免重复调用
- 使用 `React.memo` 优化组件重新渲染
- 异步加载天气数据，不阻塞首页渲染
